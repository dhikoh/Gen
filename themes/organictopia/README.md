## 🚀 Cara Memasang Tema di Blogger (`blogspot.com`)

Sangat mudah dan hanya butuh 1 menit tanpa perlu mengerti coding:

1. Buka dashboard **[Blogger.com](https://www.blogger.com)** dan pilih blog Anda.
2. Di menu sebelah kiri, klik menu **Tema** (*Theme*).
3. Di samping tombol oranye **Sesuaikan** (*Customize*), klik ikon **tanda panah ke bawah (▼)**.
4. Pilih opsi **Pulihkan** (*Restore*).
5. Klik **Upload**, lalu pilih file:  
   `organictopia-blogger-theme.xml`
6. Tunggu beberapa detik hingga proses selesai. Buka blog Anda dan tampilan blogspot langsung berubah 100% menjadi modern, premium, dan elegan!

> [!TIP]
> **Cadangkan Dulu Tema Lama:** Sebelum memulihkan, Anda bisa mengklik tanda panah (▼) lalu pilih **Cadangkan** (*Backup*) untuk menyimpan file tema lama Anda sebagai arsip aman.

## ✨ Fitur Unggulan Tema Organictopia

- **Palet Warna Botanical Luxury**: Harmoni warna Emerald (#064e3b), Sage (#10b981 / #6ee7b7), dan Earth Warm Cream (#fbfbf9).
- **Toggle Dark Mode & Light Mode**: Mode gelap mewah bernuansa *Deep Forest Night* (#0b1714) dengan transisi mulus dan penyimpanan preferensi otomatis.
- **Kalkulator Berkebun Interaktif Bawaan**:
  - *Kalkulator Dosis Pupuk Organik Cair (POC)*: Menghitung takaran ml per liter air berdasarkan fase vegetatif/generatif.
  - *Kalkulator Rasio Media Tanam*: Menghitung volume tanah, kompos, dan sekam berdasarkan ukuran pot/planter box.
- **Showcase Produk Organictopia**: Bagian etalase siap klik untuk *Balcony Micro-Nutrient Starter Pack* dan *Self-Watering Planter Kit*.
- **SEO 2026 & Core Web Vitals Ready**:
  - Skema data terstruktur JSON-LD (`BlogPosting`, `BreadcrumbList`, `WebSite`).
  - OpenGraph Facebook dan Twitter Card dinamis.
  - 100% Native Vanilla CSS & JS (Ringan, skor PageSpeed maksimal, tanpa ketergantungan jQuery atau framework berat).
